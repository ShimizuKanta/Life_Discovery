# カード表示・記録・振り返りの操作改善

対象は要件定義書の3.1、3.3〜3.6と、先行する差分のカード・カテゴリ仕様。記録から振り返りまでの見た目と操作を揃え、過去の評価を修正できるようにする。

| 項目 | 変更前 | 変更後 |
| --- | --- | --- |
| 発見カード | 内容や写真で高さが変わり、表裏が近い緑色 | 同じ画面幅では縦長の一定サイズ。文章量に応じて文字サイズを調整し、長文・フォームはカード内でスクロール。裏面は深緑、アーカイブは灰色の濃淡で区別 |
| デッキのカテゴリ | 単一選択と「全カテゴリ」ボタン | 5種類を個別に複数選択。初期状態とフィルターのリセット時はすべて選択。未選択なら該当なし |
| 記録画面 | 白い入力フォームと本文・音声入力の補足 | カードに直接書き込む見た目。日時・種類・写真のラベルを揃え、種類ボタンを低くする。写真ボタンにアイコンを付け、容量・カメラの案内はカード外へ移動。本文・音声入力の補足は削除 |
| カレンダー | 前月・翌月への移動 | 年を入力し、表示中の月を保って指定年へ移動 |
| 年次評価 | 保存後は閲覧のみ | 発見の編集画面で保存済みのスコア・コメントを修正。変更は保存時に反映し、初回の回答日時を保持する |
