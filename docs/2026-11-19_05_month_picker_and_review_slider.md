# 年月選択・記録カード・年次評価の表示調整

対象は要件定義書の3.1、3.4、3.6と先行する差分。カレンダー操作を年月見出しにまとめ、記録カードと振り返りカードの表示を調整する。

| 項目 | 変更前 | 変更後 |
| --- | --- | --- |
| カレンダー | 年入力欄が常に表示され、同じ月の別年に移動 | 「2026年11月」などの見出しを押すと、年と月を指定するダイアログが開く |
| 記録カード | 緑の枠と入力欄の間に余白が広い | カード内側と本文入力欄の上下の余白を詰める |
| 年次評価の裏面 | 保存済みの数値を表示 | 数値と同じ位置を示す閲覧用スライダーを追加。編集は発見の編集画面から行う |
