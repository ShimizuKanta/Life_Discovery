# 記録画面の配置と設定画面のタイトル

| 対象 | 変更前 | 変更後と理由 |
| --- | --- | --- |
| 設定画面のタイトル | 「あなたのペースで、大切に残す。」 | 「アプリの設定」とし、言語やバックアップを扱う画面だと分かるようにする。 |
| 記録画面のサブタイトル | 途中で改行する2行の案内 | 「初めてのこと。気づいたこと。人生の小さな発見を記録しましょう。」を標準の文字サイズで1行に表示し、入力欄までの距離を短くする。 |
| 記録画面の保存ボタン | 写真の容量とカメラの注意書きの後に表示 | カードの直下に保存ボタン、その下に注意書きを置く。上下の余白を詰め、初期表示で保存ボタンまで見渡せるようにする。写真の追加などでフォームが縦に伸びたときも、画面下部から保存できる。 |
